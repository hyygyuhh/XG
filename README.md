# 双手拉嘴

本包包含一个摄像头动作特效。

1. 解压后双击 `启动试用.bat`，使用 Microsoft Edge 打开试用台。关闭弹出的黑色窗口即可停止。
2. 点击“开启摄像头”，允许访问摄像头。
3. 点击“双指扯嘴”，双手食指接近两侧嘴角并短暂停留，再向外拉、自然张嘴。
4. 松手后恢复。再次点击“双指扯嘴”可重新触发。

画面在本机处理。嘴唇、牙齿、舌头均取自人物当前画面；未露出的口腔内容不会凭空生成。照片与插画入口仅用于查看输入，不能触发这个摄像头动作。

## 接入

宿主收到礼物后调用 `renderer.trigger('stretch-smile')`。每帧用 `faceFromLandmarks` 转换人脸关键点，手部关键点转为当前画布的像素坐标数组，再调用 `renderer.draw(source, face, timestamp, hands)`。输入图像和关键点应来自同一帧，时间戳使用递增毫秒。

返回状态为 `waiting`、`contact`、`pulling` 或 `release`，结束返回 `null`。`renderer.stop()` 取消等待或动作。动作进度条表示当前拉动幅度，保持时间跟随人物动作。

需要 WebGL2 和本地 HTTP/HTTPS 服务；本包未连接抖音礼物接口。当前为单项试用样板，参考造型、侧脸遮挡及实机直播性能尚未通过最终验收。
